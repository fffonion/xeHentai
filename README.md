# xeHentai (Rust / RustScript rewrite)

This repository is the Rust + RustScript rewrite of
[fffonion/xeHentai](https://github.com/fffonion/xeHentai). The Python release
remains the behavioural reference.

**Current status: foundation only.** The implemented scope is the configuration
pipeline (`config.py` one-time regex import and `config.rss` load/save through
the pinned RustScript SDK), the reference constants, utility functions,
translation resources, logger, and a minimal persistent Tokio worker wrapper.
The downloader, proxy layer, RPC server, WebUI and updater are **not**
implemented yet; the binary exits with status 2 after initializing
configuration and logging and says so explicitly.

## Configuration

Configuration is read from `config.rss` in the current directory. If it does
not exist, a legacy `config.py` in the same directory is imported **once** with
a regex-based reader (no Python execution, no AST), and `config.rss` is written
atomically. After `config.rss` exists, `config.py` is never read again, and
saving configuration writes only `config.rss`. `config.py` is never modified.

The import subset is intentionally narrow: `key = value` assignments with
integers, `True`/`False` (or `true`/`false`), quoted strings, and flat arrays
(plus `download_range = [[start, end], ...]`). `None`, floats, tuples, dicts,
calls, arithmetic and unknown keys are rejected with a line-numbered error.
Comment out unsupported optional lines before importing an old `config.py`.

`config.example.rss` is an example generated by the same encoder the application
uses. The 25 configuration fields and their defaults match the reference
`xeHentai/config.py`.

## Build and test

```shell
cargo build
cargo test
cargo fmt --all -- --check
cargo clippy --all-targets -- -D warnings
```

The dependency `pd-vm` is pinned to the RustScript revision
`cdb0b798d631cd7ffab6dfed3fe4b69381ed3340`.

## Behaviour comparison

`tools/compat.py` runs the fixed Python reference in isolated roots and compares
its real output with the Rust entry points. It is a development tool and is not
shipped. See `tools/cases.json` for the feature inventory and per-case status.
The comparator refuses `--verify-all` while any case remains unimplemented.

## Layout

- `src/` — Rust host code (`main.rs`, `const.rs`, `config.rs`, `i18n.rs`,
  `util/`, `worker.rs`).
- `locales/` — translated YAML resources (`en_us`, `zh_hans`, `zh_hant`).
- `rss/` — RustScript sources (separate from Rust; populated by later
  milestones).
- `config.example.rss` — example user configuration.
